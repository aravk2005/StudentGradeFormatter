Created by Arav, Pedro, Valence, and Isaac

---

## 📚 Overview

**StudentGradeFormatter** is a Java program developed for our CP317 Final Project. It processes two input files — a **student file** and a **course file** — and generates a **sorted output file** based on student IDs. The output includes each student's final grade based on their test and exam scores.

---

## 🛠 Features

- Accepts two input files:
  - `student_file.txt`: Contains student IDs and names.
  - `course_file.txt`: Contains student grades.
- Calculates final grades using test scores and final exam mark.
- Sorts the output by student ID.
- Generates a formatted output file showing student information and final grades.

---
## How to Run?

- Navigate to Main.java and hit run Java code! The output file should show up in your project workspace.
